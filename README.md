# Cumbre Feliz · Bingo Flow

Juegos de fotos para el rodaje de Cumbre Feliz: Bingo Flow, Bitácora Flow, Semillitas, Abecedario, B-I-N-G-O, Letras escondidas, Color y Bingo Sendero.

Bitácora Flow es el juego hermano del Bingo Flow: fotos de los cinco sentidos con una palabra al lado, una página privada de bitácora y ediciones (Clásica, Del color, Después de la lluvia, De las aves y De cumpleaños). En la carpeta `bitacora/` están el PDF para imprimir y las imágenes.

Semillitas es el Bingo Flow para mamá e hija: niñas que caminan con su mamá (o la persona adulta que las acompaña) buscan nueve fotos del paseo, con ideas de juego y movimiento, y la foto del centro es de las dos.

Se juegan desde el navegador del teléfono, sin cuenta. Las fotos se quedan en el teléfono de cada persona.
